# 📄 AI Resume Analyzer

🚀 A powerful AI-driven ATS Resume Analyzer that compares your resume against a job description and provides a structured analysis with match percentage, skill gaps, and improvement suggestions.

## 🌟 Features
✅ Upload PDF resumes  
✅ Compare with Job Descriptions  
✅ AI-powered Analysis (Match %, Skills, Courses)  
✅ Simple & Minimal UI like Gemini  
✅ Powered by Google Gemini API  

## 🔥 Live Demo  
[🔗 Check it out on Streamlit](https://ai-resumeanalyser-gwanbe8gxo7tltqro48t6k.streamlit.app/)

## 🛠 Tech Stack  
- **Frontend**: Streamlit  
- **AI Model**: Google Gemini  
- **Backend**: Python  
- **PDF Parsing**: PyMuPDF  
- **Deployment**: Streamlit Cloud  

## 🚀 Installation & Setup  
1. Clone the repo  
   ```bash
   git clone https://github.com/Shivikab/AI-resumeAnalyser
   cd AI-resumeAnalyzer
2. Install Dependencies
   ```bash
   pip install -r requirements.txt
3. Create a .env file and add
   ```bash
   GOOGLE_API_KEY=your_api_key_here
4. Run locally
   ```bash
   streamlit run app.py
